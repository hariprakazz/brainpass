# brainpass 🧠
### keeping memory alive

you know that feeling when you're deep into a conversation 
with an ai, making progress, figuring things out —
and then the session limit hits.

gone. everything gone.

or you switch from claude to chatgpt and have to explain 
yourself all over again from scratch. who you are, what 
you're building, what you already decided.

i got tired of that. so i built brainpass.

paste your conversation. brainpass reads it, pulls out 
what actually matters, and gives you a single prompt you 
can drop into any ai tool and continue exactly where you 
left off.

no more starting from scratch. ever.

## how to run it
1. clone this repo
2. create a .env file and add: GROQ_API_KEY=your_key_here
3. get your free key at console.groq.com
4. run: python3 main.py
5. paste your conversation
6. copy your context. carry it anywhere.
